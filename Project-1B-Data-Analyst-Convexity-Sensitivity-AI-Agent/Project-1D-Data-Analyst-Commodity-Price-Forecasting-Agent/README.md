# Project 1D – Data Analyst Commodity Price Forecasting Agent

## Overview
An interactive Power BI dashboard developed to analyze global commodity price trends, macroeconomic indicators, futures data, and forecasting insights.

## Tools Used
- Power BI
- Power Query
- DAX

## Dashboard Features
- Executive Dashboard
- Macroeconomic Analysis
- Commodity Market Analysis
- Interactive KPI Cards
- Slicers & Filters
- Trend Analysis
